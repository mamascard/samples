## Installing

**Android.** Most phones need the **arm64** file; older phones the **32-bit** one; emulators and Chromebooks
**x86_64**. Open the downloaded file on the phone and allow installing from this source when Android asks.

**Windows (64-bit).** Run the Setup file and follow the steps. It adds the app to the Start menu (and the desktop if you
tick the box) and to Windows' Apps list, where it can be uninstalled. Windows may warn the first time because the
installer is not code-signed yet: choose *More info > Run anyway*.

iPhone and Mac versions will follow.

## About these builds

- They connect to the **Mama's Card demo service**: the people, children and clinics in it are invented.
  Do not enter real patient information.
- Android builds are signed with a development key: suitable for demonstrations and pilots, not the Play Store.
- Signing in: mothers with their phone number and a code; clinic staff and administrators with the accounts given to
  them by the Mama's Card team.
